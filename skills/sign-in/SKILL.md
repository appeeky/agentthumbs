# Signing in

Only sign in to accounts the user asked you to, and only with details the user gave you for this task.

1. **Read the screen.** Find whether it wants email/username + password, a "Continue with Google/Apple/Facebook" button, or a phone number.
2. **Credentials:** tap the email field, `type` it, tap the password field, `type` it. Check each field shows the value before continuing. Never type a password the user did not give you.
3. **SSO (Continue with Apple/Google):** tap it only if the user wants to use that account. The account picker and Face ID / passcode are the user's to confirm — if it asks, hand off to the user.
4. **2FA / verification codes:** many codes arrive as a notification or a text on this same phone. When the app is waiting for a code, open Messages (or read the notification) to see it, then come back and `type` it into the field. Do not go looking through the user's messages beyond the code for the sign-in you are doing.
5. **Submit** (Sign In / Log In / Continue) — this pauses for approval. If approval is declined, stop.

If sign-in fails, report the exact error on screen rather than guessing the password again.
